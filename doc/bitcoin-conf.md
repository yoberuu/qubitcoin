# `qubitcoin.conf` Configuration File

The configuration file is used by `qbitcoind`, `qbitcoin-qt` and `qbitcoin-cli`.

All command-line options (except for `-?`, `-help`, `-version` and `-conf`) may be specified in a configuration file, and all configuration file options (except for `includeconf`) may also be specified on the command line. Command-line options override values set in the configuration file and configuration file options override values set in the GUI.

Changes to the configuration file while `qbitcoind` or `qbitcoin-qt` is running only take effect after restarting.

Users should never make any configuration changes which they do not understand. Furthermore, users should always be wary of accepting any configuration changes provided to them by another source (even if they believe that they do understand them).

## Configuration File Format

The configuration file is a plain text file and consists of `option=value` entries, one per line. Leading and trailing whitespaces are removed.

In contrast to the command-line usage:
- an option without a value is interpreted as `option=1` (which can be useful for options that do not have arguments, like `-listenonion`)
- an option with an empty value is interpreted as `option=0` (which can be useful for options that can be disabled, like `-listen`)
- lines beginning with `#` are treated as comments

Network specific options such as `-testnet` and `-regtest` should not be used together in the same configuration file.

## Configuration File Precedence

Options specified in the configuration file can be overridden by options specified on the command line. If an option is specified in both the configuration file and on the command line, the command line option takes precedence.

The `-includeconf=<file>` option can be used in the configuration file to include additional configuration files.

## Default Location

The configuration file is not automatically created; you can create it using your favorite text editor. By default, the configuration file name is `qubitcoin.conf` and it is located in the QubitCoin data directory, but both the QubitCoin data directory and the configuration file path may be changed using the `-datadir` and `-conf` command-line options.

The `includeconf=<file>` option in the `qubitcoin.conf` file can be used to include additional configuration files.

| Operating System | Default datadir | Typical path to configuration file |
| --- | --- | --- |
Windows | `%LOCALAPPDATA%\QubitCoin\` | `C:\Users\username\AppData\Local\QubitCoin\qubitcoin.conf`
Linux | `$HOME/.qubitcoin/` | `/home/username/.qubitcoin/qubitcoin.conf`
macOS | `$HOME/Library/Application Support/QubitCoin/` | `/Users/username/Library/Application Support/QubitCoin/qubitcoin.conf`

An example configuration file can be generated by running:

```bash
./contrib/devtools/gen-bitcoin-conf.sh
```

The output is placed under `share/examples/qubitcoin.conf`.

To use the example configuration file, copy it into your data directory:

```bash
cp share/examples/qubitcoin.conf ~/.qubitcoin
```
